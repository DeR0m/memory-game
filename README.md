# Memory Game

Игра на поиск пар: 16 карточек, 8 пар одинаковых изображений. Игрок открывает
по две карточки за ход и старается найти все пары за минимальное число ходов.

## Как играть

- Нажми на карточку, чтобы открыть её.
- Открой вторую карточку. Если изображения совпали — обе остаются открытыми.
- Если не совпали — обе закроются через секунду.
- Один ход — это открытие **двух** карточек.
- Цель: найти все 8 пар за минимальное число ходов.

После победы результат сохраняется в таблицу лидеров (до 10 лучших).

## Локальный запуск

### Через Live Server (рекомендуется)

1. Установи расширение **Live Server** в VS Code (`Ctrl+Shift+X` → найди
   **Live Server** → Install).
2. Открой `index.html` правой кнопкой → **Open with Live Server**.
3. Браузер откроется на `http://127.0.0.1:5500`.

### Через `npx serve` (Node.js)

```bash
npx serve
```
